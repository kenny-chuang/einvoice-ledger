# Changelog

## 1.0.0

- Vue 3 `<script setup>` 成為唯一介面，新增資料品質、分類預算與價格提醒頁面。
- 啟用 Alembic、SQLite WAL／foreign keys／busy timeout 與 migration 前五份輪替備份。
- 同步改為可追蹤狀態機、三段退避、單一執行及兩月份原子交易。
- 新增 CSV 信心等級、人工確認、對帳統計、預算門檻與原始單價低價通知。
- 新增 MQTT Discovery、Home Assistant automation package、Dashboard 範例與離線補送。
- 新增 pytest、Vue component、Playwright E2E、Docker 與多架構 CI 驗證。

## 0.2.10

- 品名包含「啤酒、威士忌、伏特加、高粱」時，CSV 匯入直接分類為「酒」。
- 回填既有待分類商品時套用相同規則，不覆蓋使用者已手動指定的分類。

## 0.2.9

- 登入按鈕改為不阻塞等待 JavaScript 導頁，由既有狀態迴圈直接觀察登入結果。
- 成功離開登入頁後立即保存原始瀏覽器 context，不再額外重新載入查詢頁造成假性 `TimeoutError`。
- 登入按鈕本身無法送出時改為顯示明確訊息並保留除錯截圖。

## 0.2.8

- 修復財政部 CSV 中賣方地址含未引用逗號所造成的欄位右移。
- 超過標準 14 欄時，從右側鎖定買方統編、數量、單價、金額與品名，將多出的地址片段合併回賣方地址。
- 匯入結果新增 `rows_repaired`，可追蹤本次自動修復的資料列數。

## 0.2.7

- 每個月份下載前重新進入發票查詢頁，避免第一個月份下載後停在結果頁而使第二個月份找不到日期欄位。

## 0.2.6

- 下載前將結果表切換為每頁 100 筆並套用，避免只匯出第一頁 10 張發票。
- 自動勾選新版頁面右側的「全部發票明細」後才觸發 CSV 下載。
- 已以 40 張發票的月份實測完整展開，並成功取得 CSV 檔案。

## 0.2.5

- 查詢送出後改為等待背景 API 產生「下載CSV檔」按鈕，不再依賴不準確的整頁 network-idle 狀態。
- 財政部查詢較慢時最多等待 60 秒，避免載入動畫期間過早拋出 `PortalChanged`。

## 0.2.4

- 支援財政部新版單一 VueDatePicker 日期區間欄位 `searchInvoiceDate`。
- 當月同步截止日自動使用今天，避免查詢尚未發生的未來日期。
- 新增新版「下載CSV檔」按鈕名稱，恢復自動下載流程。

## 0.2.3

- 登入帳號欄位改為財政部實際要求的「申請手機條碼時登記的 10 碼手機號碼」。
- 前後端阻擋誤填 `/` 開頭的手機條碼，並顯示明確提示。
- 登入提交改為等待 JavaScript API 完成或頁面跳轉，不再固定等待 12 秒後過早判定。
- 登入失敗時優先顯示財政部頁面的實際驗證訊息，並保存不含表單值的診斷資料。

## 0.2.2

- 登入成功後保留原始 Playwright 瀏覽器工作階段，避免重新開啟瀏覽器時遺失驗證狀態。
- storage state 加入 IndexedDB，提升容器重新啟動後的登入保存完整度。
- 狀態與總覽 API 改成實際開啟財政部頁面驗證，不再只以 state 檔案是否存在判定。
- 登入失效與安全驗證頁面統一標記為「需要重新登入」。
- 財政部頁面結構變更時保存不含帳密、Cookie 與欄位值的選擇器診斷資料。

## 0.2.1

- 財政部 CAPTCHA 預覽與登入共用同一個五分鐘短效瀏覽器工作階段。
- 加入 ddddocr 離線辨識與透明 CAPTCHA 白底前處理，結果預填後仍可人工修改。
- 加入 Cloudflare 安全驗證畫面的人工作業備援，不嘗試自動繞過驗證。
- 登入成功後保存 0600 權限的 Playwright storage state。
- 排程下載當月與上月 CSV 後直接執行可重複匯入。
- Home Assistant 容器改以 Xvfb 執行 headed Chromium。

## 0.2.0

- Vue 3 正式介面，所有元件採用 `<script setup lang="ts">`。
- 新增總覽、消費紀錄、商品比價、商品明細、折扣分攤、單筆修正與管理設定。
- 支援 Home Assistant Ingress 相對路徑與 Jinja 備援入口。
- 新增容器健康檢查與登入狀態備份排除。
