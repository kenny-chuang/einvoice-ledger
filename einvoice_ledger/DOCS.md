# 發票記帳助手

這個 Home Assistant App 提供私有的電子發票記帳、商品歷史比價、消費修正、分類管理與折扣分攤。

## 開始使用

安裝並啟動 App 後，按下「開啟網頁介面」。第一次使用可在總覽上傳財政部下載的 UTF-8 CSV。若要使用背景同步，請到「管理設定」手動完成手機條碼、密碼與圖形驗證碼登入。

## 資料與隱私

- SQLite 資料庫保存在 `/data/einvoice.db`。
- 財政部登入工作階段保存在 `/data/browser-state.json`，權限為 0600，並排除於 Home Assistant 備份。
- 圖形驗證碼由 ddddocr 在容器內離線辨識並預填，仍由使用者核對後送出；圖片不會傳送給第三方 OCR 服務。
- 手機條碼密碼只用於單次登入請求，不寫入資料庫或應用程式日誌。
- App 不需要 host network、特權模式或公開連接埠。

## 備援介面

1.0.0 起 Vue 3 是唯一介面。若畫面載入異常，請先確認 App 的 `/api/status`、資料庫 migration 與瀏覽器快取；需要回退時請改用保留的舊 Docker image 與切換前資料庫備份。
